# Aplikasi Penggajian Karyawan (TR Gaji)

Aplikasi Penggajian Karyawan merupakan project berbasis Java Desktop yang dibuat untuk membantu proses pengelolaan data karyawan dan penggajian.

## Teknologi yang Digunakan
- Java
- NetBeans IDE
- MySQL
- JDBC

## Fitur Aplikasi
- Login Admin
- Dashboard Karyawan
- Pengelolaan Data Karyawan
- Pengelolaan Data Gaji
- Laporan Gaji
- Cetak Slip Gaji

## Struktur Project
- `src/` – Source code aplikasi
- `nbproject/` – Konfigurasi project NetBeans
- `build.xml` – Konfigurasi proses build

## Database
Aplikasi menggunakan MySQL dengan nama database `db_c`.

Untuk menjalankan aplikasi, siapkan database MySQL lokal dan sesuaikan konfigurasi koneksi database pada file `Koneksi.java`.
